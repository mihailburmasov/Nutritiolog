# Хендоф: демо сайта Милены Лагуткиной

Актуальная демоверсия: https://mihailburmasov.github.io/Nutritiolog/  
Исходники клиента: https://disk.yandex.ru/d/o88PwWz0AFMTDQ

## Что согласовываем сейчас

Сайт размещён на GitHub Pages для согласования внешнего вида и содержания. Постоянный домен и хостинг выберут после согласования с клиентом.

По просьбе клиента на главной стоит фото с персиком, на странице «Обо мне» — с цветами, на странице услуг — в бежевом платье. Блок «Мой подход» расположен перед «Принципами моей работы». В текстах уточнено, что Милена использует БАДы при необходимости, но не продаёт их и не зарабатывает на продаже.

Первый экран главной настроен под высоту окна ноутбука. Фотоблок имеет прежнее соотношение сторон 4:5 и целиком помещается по высоте экрана. Исходный снимок более вытянутый, поэтому внутри блока используется `object-fit: cover` и часть снимка обрезается. Это последнее пожелание пользователя после варианта с узким фотоблоком, в котором показывался весь снимок.

## Заявки и запись

Форма на сайте собирает имя, контакт, формат работы и описание запроса. Выбора времени нет. После заполнения открывается Telegram с подготовленным сообщением; посетитель отправляет его самостоятельно. Автоматической отправки и серверного обработчика пока нет.

Клиент позже сообщит почтовый адрес для заявок. До этого не подключать сторонний сервис форм и не обещать автоматическую доставку. Возможность выбора свободного времени обсуждалась как отдельный следующий этап: предложен DIKIDI и ориентир 8 000 ₽ за нашу разовую настройку и встраивание виджета, но решение с клиентом ещё не согласовано.

Онлайн-оплату клиент прямо не запрашивала. Предложение о ЮKassa появилось по инициативе ассистента в черновике письма; пользователь попросил его убрать. Не считать оплату согласованным требованием.

## Что требует подтверждения

- Почтовый адрес для заявок и способ их автоматической отправки.
- Нужна ли онлайн-запись с выбором времени и какие услуги открыть для неё.
- Даты и точные названия программ образования для текстовой хронологии; сканы уже размещены на сайте.
- Новые отзывы публиковать только после согласия клиентов.
- Цены на методички, если они должны быть указаны на сайте.

## Проверка и публикация

Сайт статический, без сборки: правки HTML, CSS и JS можно проверять локально. После push в `main` проверить успешное выполнение GitHub Actions `pages-build-deployment`, затем открыть опубликованные страницы с обходом кэша. Для первого экрана ключевые правила находятся в `css/style.css` в блоке `.hero-photo-frame`.
