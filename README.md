# Nutritiolog — сайт Милены Лагуткиной

Многостраничный сайт-визитка нутрициолога, натуропата и anti-age эксперта Милены Лагуткиной. Статический HTML/CSS/JS без сборки и зависимостей — открывается прямо в браузере или разворачивается на любом хостинге/GitHub Pages.

## Структура

```
index.html      Главная
about.html      Обо мне
education.html  Образование и сертификаты
reviews.html    Отзывы клиентов
products.html   Консультация / Сопровождение / Методички
articles.html   Полезные статьи
contacts.html   Контакты и форма записи
css/style.css   Все стили (дизайн-токены в :root)
js/main.js      Мобильное меню, модалка записи, скролл-анимации
images/         Фотографии
```

## Как посмотреть локально

Открыть `index.html` в браузере, либо поднять любой статический сервер в этой папке, например:

```bash
npx serve .
```

## Запись и покупка методичек — как это работает сейчас

Бэкенда и приёма оплаты пока нет, поэтому кнопки «Записаться» и «Купить» открывают Telegram (`https://t.me/MilenaLagutkina`) с уже готовым текстом заявки — остаётся нажать «Отправить». Это временное решение, чтобы заявки уже сейчас доходили до Милены. Когда появится реальный приём оплаты (например, ЮKassa/CloudPayments для методичек и календарь для записи на консультацию), эту логику в `js/main.js` нужно будет заменить на реальную интеграцию.

## Что ещё нужно донастроить

Цены и продуктовая линейка на `products.html`, а также большая часть текстов на `index.html`, `about.html` и `education.html` — теперь реальные данные из материалов клиента (Яндекс.Диск, папка «Материалы»), не выдумка. Фото Милены — реальные (папка «Фото» на диске), тоже не заглушки.

Что по-прежнему не хватает:
- **Образование**: точные названия вузов/учебных центров и годы — известно только, что базовое образование психологическое; таймлайн на `education.html` остаётся плейсхолдером до уточнения дат.
- **Сертификаты**: сканы дипломов не предоставлены — `education.html` показывает иконки-заглушки вместо реальных изображений.
- **Отзывы**: кроме отзыва Ольги, остальные на `reviews.html` — иллюстративные примеры, ждут реальных отзывов клиентов.
- **Цены на методички**: в материалах клиента есть только названия 8 гайдов, без цен — на `products.html` кнопки ведут в Telegram с пометкой «По запросу» вместо цифры.
- **Видео**: в папке «Видео» на диске есть большие исходники (до 245 МБ) — на сайт их встраивать напрямую нельзя, нужно сначала залить на видеохостинг (VK Видео/RuTube/YouTube) и решить, где на сайте их использовать.
