# Nutritiolog — сайт Милены Лагуткиной

Многостраничный сайт-визитка нутрициолога, натуропата и anti-age эксперта Милены Лагуткиной. Статический HTML/CSS/JS без сборки и зависимостей — открывается прямо в браузере или разворачивается на любом хостинге/GitHub Pages.

## Структура

```
index.html      Главная
about.html      Обо мне
education.html  Образование и сертификаты
reviews.html    Отзывы клиентов
products.html   Консультация / Сопровождение / Методички
articles.html   Полезные статьи
contacts.html   Контакты и форма записи
css/style.css   Все стили (дизайн-токены в :root)
js/main.js      Мобильное меню, модалка записи, скролл-анимации
images/         Фотографии
```

## Как посмотреть локально

Открыть `index.html` в браузере, либо поднять любой статический сервер в этой папке, например:

```bash
npx serve .
```

## Запись и покупка методичек — как это работает сейчас

Бэкенда и приёма оплаты пока нет, поэтому кнопки «Записаться» и «Купить» открывают Telegram (`https://t.me/MilenaLagutkina`) с уже готовым текстом заявки — посетителю остаётся нажать «Отправить». Форма заявки не предлагает выбрать время. Для автоматической отправки прямо с сайта потребуется обработчик заявок; логика перехода в Telegram находится в `js/main.js`.

## Что ещё нужно донастроить

Форматы услуг и цены на `products.html`, тексты основных страниц и фотографии взяты из материалов клиента на Яндекс Диске (публичная папка «Сайт»). Уточнение клиента о БАДах учтено: Милена использует их при необходимости, но не продаёт и не зарабатывает на продаже.

Что по-прежнему не хватает:
- **Образование**: сканы дипломов и сертификатов размещены на `education.html`; для текстовой хронологии нужно отдельно подтвердить даты и названия программ.
- **Отзывы**: на `reviews.html` оставлен только реальный отзыв Ольги; новые отзывы добавляются после получения согласия клиентов.
- **Цены на методички**: в материалах клиента есть только названия 8 гайдов, без цен — на `products.html` кнопки ведут в Telegram с пометкой «По запросу» вместо цифры.
- **Заявка**: форма собирает имя, контакт, интересующий формат и описание запроса, затем открывает Telegram с подготовленным сообщением. Посетитель отправляет его самостоятельно. Автоматическая отправка без перехода в Telegram потребует серверного обработчика или отдельного сервиса форм.
